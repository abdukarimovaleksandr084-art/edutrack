# EduTrack

Платформа мониторинга успеваемости и менторства: дашборд GPA и зоны риска, календарь дедлайнов с Telegram-уведомлениями, запись к ментору, чат с преподавателем.

**Дисциплина:** Software Engineering 7224A · Университет Пучон в Ташкенте · 2026/2027

## Структура репозитория
| Папка | Содержимое |

## Правила работы
- Ветки: `main` — сдаваемая версия, остальное через ветки и pull request.
- Коммиты через GitHub Desktop, у каждого участника не меньше одного.
- Изменения базовой линии SRS только через запрос на изменение.
