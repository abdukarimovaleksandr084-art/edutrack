# Протокол проверки прототипа на пяти пользователях (NFR-07)

**Порог:** не меньше 4 из 5 участников записываются к ментору за 3 минуты без подсказок.
**Задача участнику:** «У вас долг по Java II. Запишитесь к ментору на ближайший свободный слот».
**Как проводим:** модератор зачитывает задачу и молчит; время от первого клика до экрана «Вы записаны»; если не справился за 5 минут или просит помощи — «с подсказкой».
